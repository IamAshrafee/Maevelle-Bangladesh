# Maevelle Product Completion V2

This is the repository-native continuity system for product-development work.
It records current evidence and the exact safe continuation point; it is not a
historical implementation archive or a substitute for source review.

Start a new product-completion session by reading `state.json`,
`current-focus.md`, this directory's system map and registry, then confirming
the relevant claims against Git and source. Repository evidence outranks these
notes if they disagree.

Use one active area at a time. Create an `areas/<area>/` directory only once an
area is actively assessed or worked. `VERIFIED_COMPLETE` requires the evidence
defined in `verification-policy.md`; code volume, old reports, or a page route
are not sufficient.
