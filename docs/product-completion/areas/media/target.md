# Media Completion Target

- Stable tenant-owned assets distinct from physical originals, renditions, and usages.
- Direct-to-object-storage capable upload sessions with confirmation and expiry.
- Local development and S3-compatible/Cloudflare R2 adapters behind one port.
- Worker validation, EXIF-safe image processing, deterministic renditions, retries, and stale-work recovery.
- Images and private documents with bounded types, sizes, names, and signatures.
- Logical folders, tags, metadata, uploader/source attribution, search, filters, and server pagination.
- Domain-authoritative Product/option/Variant placement and secure verified-purchase Review uploads.
- Visibility rules, authenticated private delivery, optimized public delivery, and stable asset URLs.
- Usage-aware archive, trash, restore, delayed purge, abandoned-upload cleanup, and storage health checks.
- Tenant/capability enforcement, optimistic concurrency, audit evidence, indexes, and composite tenant foreign keys.
- Responsive Admin workflows and Storefront rendition/selection correctness without duplicate legacy upload paths.
