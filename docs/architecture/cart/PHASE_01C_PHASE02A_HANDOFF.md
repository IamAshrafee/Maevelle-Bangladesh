# Phase 01-C phase02a handoff

Phase 02A can start as a separate commerce assignment using the supported guest authority and mutation contract. Preserve the scoped owner check before mutation, caller-observed revision, immutable receipt and exact replay, atomic outbox and cookie-only session recovery. Keep intent revisions distinct from current evaluation changes. The following contract is proposed for implementation and acceptance.
